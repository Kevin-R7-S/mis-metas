# Mis metas para este trimestre

Aprender a utilizar variables, condicionales, ciclos y funciones para crear programas

## 2. Mejorar mi lógica de programación

Resolver ejercicios de programación para aprender a analizar problemas y encontrar soluciones.

## 3. Aprender Git y GitHub

Practicar comandos como git init, git add, git commit y git log para guardar y controlar versiones de mis proyectos.

Crear páginas web utilizando HTML, CSS y JavaScript, y mejorar la presentación de mis proyectos.

## 5. Ser constante con mis estudios

Dedicar tiempo cada semana a practicar programación y cumplir con las actividades del SENA.


## Mi compromiso

Trabajar cada semana para cumplir estas metas, aprender de mis errores y mejorar mis habilidades como aprendiz de Análisis y Desarrollo de Software.
