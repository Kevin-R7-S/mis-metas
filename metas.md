# Mis metas para este trimestre

## 1. Aprender JavaScript

Aprender a utilizar variables, condicionales, ciclos y funciones para crear programas

## 2. Mejorar mi lógica de programación

Resolver ejercicios de programación para aprender a analizar problemas y encontrar soluciones.

## 3. Aprender Git y GitHub

Practicar comandos como git init, git add, git commit y git log para guardar y controlar versiones de mis proyectos.

## 4. Mejorar en desarrollo web

Crear páginas web utilizando HTML, CSS y JavaScript, y mejorar la presentación de mis proyectos.

## 5. Ser constante con mis estudios

Dedicar tiempo cada semana a practicar programación y cumplir con las actividades del SENA.

##6. Practicar inglés
Estudiar un poco cada semana para mejorar mi comprensión y vocabulario.

##7. Crear un portafolio personal
Diseñar una página web para mostrar mis proyectos y lo que voy aprendiendo.

- Revisar mis metas al final de cada mes.


## Mi compromiso

Trabajar cada semana para alcanzar estas metas, aprender de mis errores y mejorar mis habilidades como aprendiz del programa de Análisis y Desarrollo de Software.

## Mis proyectos

1. Mi objetivo es convertirme en un gran programador, desarrollar mis habilidades cada día y nunca dejar de aprender.

2. Quiero crear proyectos que sean útiles para la sociedad y que puedan ayudar a las personas en su vida diaria.
